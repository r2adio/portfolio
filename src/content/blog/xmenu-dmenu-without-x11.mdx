`xmenu` is a lightweight menu utility inspired by `dmenu`. Unlike `dmenu`, it does
not depend on X11, so it runs on Wayland and other non-X environments.

MDX lets you use JSX and exported values inline. This post is about
{`xmenu v${version}`} and was published on
{new Date(frontmatter.date).toDateString()}.

## What is xmenu

`xmenu` renders a menu of items to standard output. You pipe a list of entries in,
it shows a menu, and prints the selected line back — classic `dmenu` behaviour,
but without the X11 dependency. The exported `version` above renders inline here
too: {version}.

### How it differs from dmenu

- No X11 or XWayland dependency.
- Pairs well with Wayland compositors such as `sway` or `hyprland`.
- Keeps the same keyboard-driven workflow.

## Installation

Build it from source and put the binary on your `PATH`:

```sh title="install-xmenu.sh"
git clone https://github.com/example/xmenu
cd xmenu
make && sudo make install
```

A small TypeScript example, with line numbers enabled:

```ts title="examples/launcher.ts"
import { pick, run } from "./xmenu";

const items = ["firefox", "kitty", "code"];
const choice = await pick(items, { prompt: "run:" });

if (choice) {
  await run(choice.split(/\s+/)[0]);
}
```
